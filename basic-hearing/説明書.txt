求人ヒアリングフォーム (Recruitment Hearing Form) v3.0.0
「求人飲食店ドットコム」への掲載依頼および、求人情報の社内管理を円滑に行うための高機能Webフォームです。
飲食店特有の複雑な雇用形態や店舗情報を、直感的なインターフェースで収集・書き出しできます。

🚀 主な機能
ステップ型UI: 「店舗情報」と「求人条件」を切り分けて入力し、入力漏れを防ぎます。
動的案件カード: 職種ごとに求人カードを無制限に追加可能。
コピー作成機能: 「正社員」の条件を「アルバイト」にコピーするなど、入力の手間を大幅に削減。
バリデーション: 重複する職種・雇用形態の組み合わせを自動検知し、警告を表示。
データポータビリティ:
CSVダウンロード: 入力内容をCSV形式でローカル保存。
CSV読み込み: 保存したCSVをアップロードして、過去のデータを瞬時に復元。
オートセーブ: ブラウザのローカルストレージを利用し、作業内容を自動保存（誤って閉じても安心）。
レスポンシブ設計: PCだけでなく、スマートフォンのブラウザからも快適に入力可能。

📋 使い方
1. 初期設定
ヘッダーの「クライアント情報」エリアに 法人名 または 店舗名 を入力してください。これがデータの識別キーとなります。

2. STEP 1: 店舗情報の入力
所在地、アクセス、連絡先、SNSアカウントなどの基本情報を入力します。
「お店のアピール」セクションでは、採用背景や職場の雰囲気を具体的に記入してください。

3. STEP 2: 求人情報の入力
「新規案件を追加」ボタンで求人カードを作成します。
給与、勤務時間、休日などの詳細条件を設定してください。
同じ内容の別形態（例：ホール・正社員をホール・アルバイトにする場合）を作成する際は、「コピーして作成」が便利です。

4. データの送信・保存
送信: 全入力完了後、最下部の「すべての情報を送信する」をクリックしてください。
バックアップ: 途中で作業を中断する場合や、控えを手元に残したい場合は「CSVをダウンロード」をクリックしてください。

🛠 技術スタック
Frontend: HTML5 / CSS3 / JavaScript (Vanilla JS)
CSS Framework: Tailwind CSS
Icon / Font: Google Fonts (Noto Sans JP)
Data Format: CSV (UTF-8 with BOM)

⚠️ 注意事項
重複制限: 同じ職種かつ同じ雇用形態（例：調理スタッフ・正社員 × 2件）は、掲載ルールに基づき登録できません。
ブラウザ依存: 自動保存機能はブラウザの localStorage を使用します。シークレットモードやキャッシュ削除を行うとデータが消去されるため、重要なデータは必ずCSVで保存してください。
必須項目: 赤色の「必須」ラベルがついた項目が未入力の場合、送信時にエラーが表示されます。
